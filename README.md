# UniversitySystem - Университетская информационная система

## 📋 Описание

Университетская информационная система на WPF с базой данных SQL Server. Система включает модули для администратора, преподавателя и студента с разграничением прав доступа (RBAC).

## 🏗️ Архитектура

### Основные компоненты:

1. **Модуль аутентификации и авторизации (RBAC)**
   - Единый сервис `RbacService` для управления сессией и правами
   - Хеширование паролей (SHA256)
   - Проверка прав доступа по ролям

2. **Модуль администрирования**
   - Управление структурой вуза (факультеты, кафедры, группы)
   - Управление учебным планом (дисциплины, распределение по группам)
   - Управление пользователями (создание, редактирование)

3. **Модуль преподавателя**
   - Просмотр групп и дисциплин
   - Ввод и редактирование оценок
   - Формирование журнала и экспортом в Excel

4. **Модуль студента**
   - Просмотр расписания
   - Мониторинг успеваемости в реальном времени
   - Уведомления о задолженностях

5. **Модуль отчетности**
   - Генерация отчетов по успеваемости
   - Рейтинги студентов
   - Экспорт данных в Excel

## 🚀 Установка и запуск

### Требования:
- .NET 10.0 SDK
- SQL Server LocalDB
- Visual Studio 2022 или VS Code

### Шаги:

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd UniversitySystem
   ```

2. **Настройка базы данных**
   - Проект использует LocalDB по умолчанию
   - Строка подключения: `Data Source=(localdb)\MSSQLLocalDB;Database=UniversityDB;...`
   - При первом запуске база данных будет создана автоматически

3. **Запуск приложения**
   ```bash
   dotnet build
   dotnet run
   ```

### Тестовые учетные записи:

Для тестирования создайте пользователей через админ-панель:
- **Администратор**: роль "Admin"
- **Преподаватель**: роль "Teacher"
- **Студент**: роль "Student"

## 🔧 Технические особенности

### Безопасность:
- Хеширование паролей (SHA256)
- Разграничение прав доступа (RBAC)
- Защита от SQL-инъекций (используется EF Core)

### Архитектурные решения:
- **Единый RbacService** вместо дублирующих сервисов
- **Асинхронные операции** с базой данных
- **Логирование** всех значимых событий
- **Обработка ошибок** на всех уровнях

### Удаленные/объединенные классы:
- `Services/RbacService.cs` - объединен с корневым `RbacService.cs`
- `Utils/SessionContext.cs` - функционал перенесен в `RbacService`

## 🔧 Изменения в проекте

### Исправленные ошибки:
1. Конфликт между `RbacService.IsExpired` (свойство) и методом
